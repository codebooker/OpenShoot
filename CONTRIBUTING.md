# Contributing

Use the setup in the README. Run `npm test` and `npm run build` before submitting changes. Native worker changes also require `npm run build:raw` on macOS.

Keep edits nondestructive, validate AI responses, preserve checkpoint compatibility, and test the workflow affected. Use generated fixtures for tests and screenshots. Do not commit personal photos, account files, absolute home-directory paths, cached libraries, model weights, or build outputs.

PRs should explain the behavior changed, how it was verified, and any camera/platform limitations. New dependencies/assets need provenance and license notices. Preserve the notices accompanying vendored components.
